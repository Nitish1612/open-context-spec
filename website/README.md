# ULCS website

No documentation site is built yet — this directory is reserved for one
(e.g. via Docusaurus or a similar static-site generator over
`specification/v1/`). Until then, the canonical documentation is:

- [`specification/v1/`](../specification/v1) — the draft specification,
  vocabulary, precedence, provenance, security, token-policy, and
  interoperability documents.
- [`examples/`](../examples) — runnable example documents.
- Root [`README.md`](../README.md) — project overview and quick start.

See the roadmap in the root README for "documentation site" as a planned
addition. `docs/` below is left in place as the intended mount point for
that future site's content.
